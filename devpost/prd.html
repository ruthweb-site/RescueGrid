Detailed Feature Behaviors

1. Multi-factor Scoring Formula

  • Exposure (0–40 pts): Hazard severity by zone.
  • Vulnerable Pop (0–30 pts): Elderly/children count.
  • Road Penalty (0–20 pts): Cut=20, At Risk=10, Open=0.
  • Depot Distance (0–10 pts): Transit difficulty.
  • Auditable: Points sum identically to the total score.

2. "Why this ranking?" Expander

  • Displays exact point breakdown for all 4 factors.
  • Generates deterministic template explanation line (e.g., "Ranked #2: high flood exposure and 340 vulnerable residents, with the access road at risk.").
  • Zero AI hallucinations in factor justification.

3. Shortfall & Deficit Presentation

  • Summary strip above table: Total shortfall per resource.
  • [✓] Fully Allocated when Gap = 0.
  • [▲] Partial when partially supplied.
  • [✖] Unmet Need when zero stock received.

4. Cross-Surface Node Sync

  • Hover node: Tooltip with name, risk, rank, population.
  • Click node: Highlights map node, highlights triage row, auto-expands "Why this ranking?", highlights allocation row.
  • Click table row: Synchronizes selection to map node.
  • Click empty canvas: Clears selection state.

5. AI Action Brief & Verification

  • Skeleton loader displays while AI generates brief.
  • Every inventory number in the output is validated against the computed allocation table.
  • Badge: AI-drafted, validated.

6. Template Fallback Engine

  • Activates if API times out or validation check fails.
  • Badge: Standard plan (AI unavailable) or Standard plan (AI output failed validation).
  • Guarantees zero unvalidated numbers shown to user.
