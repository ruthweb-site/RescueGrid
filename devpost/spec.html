Component Specifications

server.js

Serves static assets & proxies API

Zero external npm dependencies. Serves HTML/JS/CSS with proper MIME types. Exposes POST /api/brief, injects API key from .env, enforces a 10s timeout, and forwards compact prompt to model.

src/engine/scoring.js

Implements prd.md > Risk Scoring

Computes 4 factor points: Exposure (0–40), Vulnerable Population (0–30), Road Access Penalty (0–20), Depot Distance (0–10). Rounds each factor to 1 decimal place and sums rounded values. Deterministic tie-breaking.

src/engine/allocation.js

Implements prd.md > Resource Allocation

Scales community demand by scenario severity: baseline × (exposure / 40) with a 25% floor. Distributes stock greedy-by-rank. Partial allocation at boundary; residual deficit calculated for each community.

src/components/map.js

Implements prd.md > Interactive SVG Map

Draws vector SVG map: roads styled by status (Open, At Risk, Cut), communities rendered as dual-coded badges (rank + color + icon), central depot marker, and interactive hover tooltips and selection sync.

src/services/aiBriefing.js

Implements prd.md > Action Brief Guardrail

Parses structured JSON response. Replaces variable placeholders (e.g. {{c1.food}}) with verified numbers. Validates rank order and rejects unallowlisted digits before displaying.

tests/engine.test.js

Automated Verification Suite

Runs natively via node --test. Asserts factor breakdown sums match total score, ties resolve consistently, allocations never exceed slider stock, and boundary shortfalls calculate accurately.
